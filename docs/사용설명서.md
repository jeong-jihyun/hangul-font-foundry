# Glyphroom 사용 설명서 (v1.0)

## 0. 처음 한 번
1. 앱 열기: https://hangul-font-foundry.vercel.app
2. 위쪽 **🔒 폰트 저장 잠김** 줄을 누르고 비밀번호(PIN)를 넣습니다. 열면 그린 글자가 GitHub에 저장되어 폰·PC 어디서나 이어서 작업할 수 있습니다.
3. 위쪽 **작업 중인 폰트**를 눌러 새 폰트를 만들거나 이름을 바꿉니다.

## 1. 글자 그리기 (앱 안)
- 홈의 **'가' 그리기** 또는 글리프 탭 → 글자 누르기 → **✎ 이 글자 그리기**
- 도구
  - **펜**: 점을 찍으면 직선, 누른 채 끌면 곡선. 첫 점을 다시 누르면 도형이 닫힘
  - **사각형·원**: 끌어서 크기 정하기
  - **점 추가**: 도형 선 가까이를 누르면 점이 생김
  - **선택**: 점·손잡이·도형을 끌어 옮기기. 아래 칸에 숫자로 X·Y·너비·높이 입력, 화살표로 1칸씩
  - **화면 이동·확대**: 두 손가락(폰), 마우스 휠(PC), 오른쪽 위 ＋ － ⤢
- **격자**: 끔/5/10/25/50칸. 켜면 점이 칸과 바닥선(800)에 붙습니다.
- **밑그림**: 손글씨·스케치 사진을 깔고 투명도·크기·위치를 맞춰 따라 그립니다(저장되지 않음). 다른 폰트를 따라 그리면 안 됩니다.
- **저장**: 오른쪽 위 저장(PC는 Ctrl+S). GitHub에 기록되고 자동으로 검수됩니다. **‹ ›** 로 이전/다음 글자.
- **더 보기**: SVG 파일 불러오기(자동 정리), SVG 내려받기, **SVG-Edit에서 열기**(PC), 모두 지우기
- 안쪽에 넣은 도형은 구멍이 되고(예: ㅇ), 겹친 획은 채워집니다. 화면에 보이는 그대로 폰트가 됩니다.

## 2. 다른 프로그램에서 그린 경우
- 속이 채워진 도형으로 그리고, 선(stroke)은 '윤곽선으로 변환'합니다.
- 파일 이름을 `U+AC00.svg` 처럼 붙여 zip으로 묶어 **검수 탭**에 올립니다. 그룹·변형·원·상대좌표·크기 차이는 자동 정리됩니다.
- 한두 글자는 글리프 탭의 **SVG 파일 올리기**로 바로 넣습니다.

## 3. 폰트 만들기
- **빌드 탭** → 글꼴 이름 확인 → (필요하면) **글자 너비** 조정 → **시험용 폰트 만들기**(필수 2,438자가 다 없을 때) 또는 **정식 폰트 만들기**
- 끝나면 맨 위에서 **폰트 파일 받기**, 아래에서 문장을 직접 써 보기. 서버 보관은 6시간입니다.

## 4. 다른 기기에서 이어서
- 같은 비밀번호로 열고 폰트를 고르면 저장된 글자를 불러옵니다. 검수 탭의 **검수 실행**을 한 번 누르면 빌드까지 바로 됩니다.

## 확인할 수 없는 것
글자 디자인 품질, 윈도우·맥 표시, 마켓 심사 기준. 라이선스·상품 문구는 초안입니다.
